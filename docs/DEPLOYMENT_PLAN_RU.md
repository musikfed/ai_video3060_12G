# План чистого развёртывания: QUALITY FIRST

## Цель
Личная студия, скорость не критична. Качество кадра, естественная анатомия, сохранение персонажа и осмысленное синхронное аудио — обязательные цели. Базовый экспорт **1280×720, H.264/AAC, 24fps**; 1920×1080 — дополнительный режим после успешных испытаний. Исходное разрешение генерации и наличие апскейла всегда указывать честно.

## Аппаратная граница
CORE: RTX 3060 12GB, RAM 48GB DDR3, 2 × Xeon, Ubuntu 24.04, /1tbdisk. Квантование, block swap и CPU offload допустимы; они не превращают RAM в VRAM и могут замедлять вычисления. За один раз одна GPU-тяжёлая модель; остальные выгружены.

## Кандидаты для независимого испытания
1. **LTX-2 с GGUF/low-VRAM workflow и нативным аудио** — проверить воспроизводимость на CORE, разборчивость русского, соответствие движений и звуков, 720p.
2. **Более новые LTX** — только после проверки размеров, требований, лицензии и реального 12-ГБ workflow; не обещать совместимость до теста.
3. **Wan 2.2 I2V A14B GGUF** — кандидат на более качественное движение по исходному кадру, но без нативного звука. Для него отдельно потребуется аудиодвижок и синхронизация.
4. Иные свободно доступные кандидаты только после конкретного измерения качества на схожем GPU. Не принимать рекламные примеры за гарантированный результат.

## Порядок
**A. Полная очистка** выделенных старых папок и служб после просмотра dry-run, без удаления общего Ollama и других ComfyUI.

**B. Чистая структура:** /1tbdisk/ai_video3060_12G (код), отдельный каталог data/models/cache/results, никакой прежней веб-морды. Сервисы только вручную, не по автозапуску.

**C. Стенд модели без UI:** скачать ровно один выбранный комплект весов, записать SHA, лицензию, граф, установленные пакеты. Пробная T2V/I2V-сцена с простым движением и короткой русской речью. Не скачивать сразу все модели.

**D. Приёмка:** качество анатомии и композиции, сохранение референса, различимые реальные движения, наличие и синхронность звука, 720p на выходе, отсутствие OOM; сохранить seed, промпт, настройки, RAM/VRAM peak и время. Указывать, если исходно генерировалось не 720p.

**E. Сравнение:** при неудаче поменять граф/квантование или модель, а не переписывать UI. Принять основной движок по **качеству**, а не секундам.

**F. Backend:** общая очередь GPU, менеджер моделей, рабочие проекты и сохранение характеристик персонажей, проверка результатов, экспорт с реальным аудио.

**G. Web GUI:** проектировать **только по эскизу пользователя**, который ещё будет предоставлен.

## Очистка старой установки
`scripts/cleanup-old-install.sh` сначала показывает dry-run. При явном запуске удаляет *только* старые директории /1tbdisk/ai_video3060_12G и /1tbdisk/ai_video3060_12G-data (включая Wan/SDXL чекпоинты, dedicated ComfyUI 8189, медиатеку, результаты) и две user systemd-службы. **Ollama, ACHEWIW ComfyUI 8188 и чужие проекты не затрагивает.** Проверь и сохрани полезные PNG/MP4 до очистки.

Ни одна новая модель не установлена и не испытана этим коммитом.
